# إنشاء العقود — أصول ريزيدنس

أداة داخلية في ملف واحد (`index.html`) لإنشاء العقود:

- **إيجار:** عقد مالك · عقد مستأجر (عربي/إنجليزي) · عقد مستأجر (عربي)
- **بيع:** وعد بالبيع · عقد بيع ابتدائي · عقد بيع نهائي

المخرجات: PDF (من نافذة الطباعة) و Word حقيقي `.docx`.

## ملاحظات

- كل البيانات (العقود المحفوظة وبيانات الشركة الثابتة) بتتحفظ في متصفح الجهاز فقط — مفيش حاجة منها في الكود ولا بتترفع لأي سيرفر.
- بيانات الشركة بتتكتب مرة واحدة من زرار «⚙ بيانات الشركة».
- خد نسخة احتياطية Excel بشكل دوري من زرار «نسخة احتياطية Excel».
